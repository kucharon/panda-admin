# 熊猫后台 英文版

熊猫睡眠管理后台交互原型（单文件 HTML，无外部依赖）。

## 打开方式

直接用浏览器打开 `index.html`，或访问 GitHub Pages。

## 原型内容

- 内容配置管理 → 课程配置：内容配置（新）、内容配置（旧）、混音配置、榜单配置、搜索发现配置
- 内容配置（新）：单曲 / 白噪音 / 系列课分支；当前分类、封面、介绍页、内容权限、精选与动态排序
- 系列课：查看 → 小课列表 → 添加小课（封面仅 1:1）
- 精选白噪音：先配头部 → 查看 → 添加 2–7 条白噪音音频（进入精选混音）
- 榜单配置：首页 TOP1–10，搜索页热门榜前 5
- 混音配置：上传封面 + 多选 2–7 条白噪音 ID
- 搜索发现配置：搜索词与后缀标记
